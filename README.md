# اسکیل‌های سناریونویسی یوتوبوست برای Claude

سه اسکیل که به Claude یاد می‌دن سناریوی ویدیو رو طوری بنویسه که بیننده تا آخر بمونه.

ساخته‌شده توسط **یوتوبوست**
اینستاگرام: [@youtoboost](https://instagram.com/youtoboost) · [@aryan.jahanshah](https://instagram.com/aryan.jahanshah)

---

## سه اسکیل

| اسکیل | کارش | کی استفاده کنی |
|-------|------|----------------|
| **`power-hook`** | ساختن هوک با شش بلوک کلمه: سوژه، عمل، هدف، تضاد، اثبات، زمان | برای جمله‌ی اول ویدیو |
| **`curiosity-ladder`** | چیدن ساختار ویدیو با شش پله: تحریک، شیفتگی، انتظار، تأیید، محبت، مکاشفه | برای نقشه‌ی کلی و پیدا کردن نقطه‌ی ریزش |
| **`open-loop`** | نوشتن بدنه با چرخه‌ی ریسک، سؤال، فریب و قلاب دوباره | برای متن اصلی و جاهای گذار بین بخش‌ها |

**ترتیب پیشنهادی برای یه سناریوی کامل:**
`curiosity-ladder` (نقشه) ← `power-hook` (هوک) ← `open-loop` (بدنه)

---

## نصب در Claude (اپ یا سایت claude.ai)

1. بالای همین صفحه روی دکمه‌ی سبز **Code** و بعد **Download ZIP** بزن.
2. فایل رو از حالت فشرده خارج کن. سه پوشه داری: `power-hook`، `curiosity-ladder`، `open-loop`.
3. هر پوشه رو جداگانه زیپ کن (راست‌کلیک ← Compress یا Send to ← Compressed folder).
4. توی Claude برو به **Settings ← Capabilities ← Skills** و روی **Upload skill** بزن.
5. فایل zip هر پوشه رو آپلود و اسکیل رو روشن کن.

> اسکیل‌ها روی پلن‌های پولی Claude در دسترسن. اگه گزینه‌ی Skills رو نمی‌بینی، اول توی تنظیمات قابلیت **Code execution** رو روشن کن.

### نصب در Claude Code

پوشه‌ی هر اسکیل رو داخل `~/.claude/skills/` کپی کن:

```bash
git clone https://github.com/Arixja/youtoboost-skills.git
cp -r youtoboost-skills/{power-hook,curiosity-ladder,open-loop} ~/.claude/skills/
```

## روش استفاده

بعد از نصب، کافیه عادی از Claude بخوای. خودش اسکیل مناسب رو انتخاب می‌کنه:

- «برای ویدیوی "چرا پیجم رشد نمی‌کنه" یه سناریوی ۶۰ ثانیه‌ای بنویس.»
- «این هوک رو قوی‌تر کن: …»
- «این سناریو رو بخون و بگو بیننده کجاش می‌ره.»
- «این سناریو رو با اوپن لوپ بازنویسی کن.»

برای نتیجه‌ی بهتر، این‌ها رو هم بهش بگو:
- مخاطبت کیه
- نتیجه یا ارزش اصلی ویدیو چیه
- یه داستان یا تجربه‌ی واقعی که بشه توی سناریو آورد
